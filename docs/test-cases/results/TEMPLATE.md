# <os> · <provider> · <db> 테스트 결과

> 파일 이름: `results/<os>-<provider>-<db>.md` (예: `windows-claude-mysql.md`)
> 아래 "실행기 보고서" 에 `run-cases.mjs --out` 결과를 붙이고, 위쪽에 결론을 적는다.

## 결론

| 항목 | 내용 |
|---|---|
| 실행일 · 실행자 | YYYY-MM-DD · @id |
| 설치 폴더 · 모델 | `<경로>` · `<모델명>` |
| 샘플 데이터 | (README 1장 기준인지, 다르면 차이) |
| 결과 | ✅ N · ⚠️ N · ❌ N |
| 최종 판정 | 통과 / 실패 (이슈 링크) |

## REVIEW · FAIL 항목

| ID | 등급 | 원인 분류 | 판단 · 조치 |
|---|---|---|---|
| TC-xx | ⚠️ | LLM 쿼리 (CONCAT 계산 컬럼) | 정상 — 같은 테이블 다른 컬럼은 올바르게 매칭 |
| D-xx | ❌ | 수정 코드 / 스키마 파일 / 서버 설정 | #이슈번호 |

원인 분류: **수정 코드** (매칭 로직 버그) · **스키마 파일** (`tables/*.md` 누락 · 오류) · **LLM 쿼리** (계산 컬럼 · 다른 테이블 조회) · **서버 설정** (SQL 허용 규칙 · 민감 컬럼 필터) · **환경** (DB 접속 · 샘플 데이터 차이)
